# agy history fallback

AgentsView holds no Antigravity CLI (`agy`) sessions yet (#90 part A), so its
search misses decisions made only in agy, and hits from other harnesses hide
that gap. Until the hub indexes agy, run this fallback after **every**
`agentsview-finding-history` search, not only when AgentsView comes back empty
(that skill is generated by `agentsview skills install` and overwritten on
refresh, so the fallback lives here). Run it on each machine that ran agy (Mac
host, pc, VM); the files stay local to that machine.

## Where agy keeps history

Under `~/.gemini/antigravity-cli/` (override with `--root` or `AGY_HISTORY_ROOT`):

- `conversations/<uuid>.db`: binary, but message text is stored as plain text.
  Expect noise: the same text repeats several times per file.
- `brain/<uuid>/<artifact>.md`: `implementation_plan.md`, `walkthrough.md`,
  `learning_proposal.md`, `task.md`. Each has a `<artifact>.md.metadata.json`
  with a `summary` and an `updatedAt` timestamp. The `<uuid>` matches the
  conversation. `brain/<uuid>/.system_generated/` holds agy internals; skip it.

## Scripted fallback

`scripts/agy-history.py` is stdlib-only and runs under `/usr/bin/python3`
(3.9). `--json` and `--root` go before or after the subcommand. Exit codes: 0
matches, 1 searched but nothing matched, 2 nothing could be read (missing root or
`conversations/`/`brain/` dir, every file unreadable) or bad usage (empty term,
`--limit`/`--snippets` below 1). Warnings and "N files skipped
(unreadable/malformed)" go to stderr: a miss with skipped files is not proof of
absence. `read` refuses symlinks and paths outside the root, caps output at
200 KiB and strips control characters.

```sh
py=~/.agents/skills/agy-history-fallback/scripts/agy-history.py
python3 "$py" search "D155"          # conversations holding the term (case-insensitive), deduped snippets
python3 "$py" search "D155" --json   # same, as JSON (one row per uuid; .db-wal sidecars merged)
python3 "$py" brain --term Doppler   # brain artifacts, newest updatedAt first, with summaries
python3 "$py" brain --limit 1000     # many artifacts (default 20)
python3 "$py" read 0f3c9a51          # implementation_plan, walkthrough, learning_proposal of one uuid (prefix ok)
python3 "$py" read <uuid> --kind task
python3 "$py" --self-check           # verify the script on a scratch fixture
```

`search` marks hits whose conversation also has a `brain/<uuid>` directory;
read those artifacts first, since they summarize the conversation.

## Manual equivalent

When the script is unavailable:

```sh
rg -a -l -i 'D155' ~/.gemini/antigravity-cli/conversations/
strings ~/.gemini/antigravity-cli/conversations/<uuid>.db | rg -i 'D155' | sort -u
rg -l -i 'D155' -g '{implementation_plan,walkthrough,learning_proposal}.md' ~/.gemini/antigravity-cli/brain/
```

`strings` splits non-ASCII text; the script keeps UTF-8 whole. Let `rg -g`
filter the artifact names: a shell glob like `brain/*/{a,b}.md` aborts in zsh
when any one pattern matches nothing.

## Reporting

Cite the conversation uuid, the artifact path and its `updatedAt`, and say the
finding came from the on-disk agy fallback, not AgentsView.
